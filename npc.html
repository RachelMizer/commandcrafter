NPC commands

Dialogue buttons, vendors and the command-block chains behind them. Each generator returns the whole set of commands in the order they need to run — paste the group straight into one dialogue button.

Open a dialogue scene /dialogue

Sends a player into a named scene on a tagged NPC. This is what a "back" or "tell me more" button runs to move between scenes.

The tag on the NPC entity, not its display name.
Leave blank for the NPC's default scene.

Vendor sells to the player buy button

The player spends points and gets items. Produces both branches — the "not enough" message and the successful purchase — with the score ranges worked out so they can't overlap.

Used in the success message.
Amount is optional and defaults to 1.

Vendor buys from the player sell button

The player hands over items and gets points. Checks the player's inventory with hasitem before taking anything.

Set up a scoreboard /scoreboard

Every currency, quest flag and purchase counter needs an objective before any vendor button will work.

No spaces — this goes inside selectors.
Shown on screen; spaces are fine here.

Livestock / summon vendor redstone chain

A dialogue button can't summon a mob on its own, so it sets a flag score and powers a redstone block. Command blocks in the world do the summoning and reset themselves afterwards.

One per vendor per animal, so shops don't cross-fire.

Tag-driven purchase chain command blocks

The other way round: the dialogue button just tags the player, and a pair of command-block chains sort out success and failure. Easier to debug than putting everything on the button.

Lock an area to tagged players access control
